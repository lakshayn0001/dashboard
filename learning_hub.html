Roadmap & Core Architecture Track 02

System Design & Distributed Systems Engineering

Designing highly available, horizontally scalable distributed applications capable of handling millions of concurrent requests.

Module 1: Scalability & Caching

Cache-Aside & Write-Through

Multi-tier caching using Redis/Memcached. Cache stampede mitigation, TTL invalidation strategies, and distributed locking via Redlock.

Module 2: Messaging & Events

Apache Kafka & Event Sourcing

Partition offsets, consumer groups, exactly-once processing semantics, dead-letter queues, and CQRS synchronization.

Module 3: Data Tier Resiliency

Sharding & Consensus

Consistent hashing, horizontal database sharding, master-replica failover, CAP theorem tradeoffs, and Raft consensus mechanics.

Roadmap & Infrastructure Track 03

Cloud Architecture & DevOps Infrastructure

Containerization, Kubernetes cluster orchestration, declarative Terraform infrastructure, and zero-downtime CI/CD pipelines.

Module 1: Containers

Docker Multi-Stage & Rootless

Minimal Alpine/scratch images, build cache optimization, non-root user security execution, and Docker Compose development setups.

Module 2: Orchestration

Kubernetes (K8s) & Helm

Deployments, Services, Ingress-Nginx, ConfigMaps, Secrets, Horizontal Pod Autoscaling (HPA), and Helm chart packaging.

Module 3: Pipelines & IaC

GitHub Actions & Terraform

Automated test/build matrices, artifact generation, declarative Terraform provisioning on AWS/Azure, and OpenTelemetry observability.

Roadmap & Emerging Tech Track 04

Applied AI & LLM Systems Engineering

Building production LLM applications: Retrieval-Augmented Generation (RAG), vector databases, agentic tool-use, and prompt evaluations.

Module 1: Vector Architecture

Embeddings & Vector Databases

High-dimensional embeddings, similarity metrics (cosine, dot product), HNSW indexing graphs, and Qdrant / Pinecone cluster management.

Module 2: Advanced RAG

Hybrid Search & Reranking

Parent-child chunking, BM25 + dense hybrid search, cross-encoder rerankers, metadata filtering, and hallucination reduction.

Module 3: Autonomous Agents

Tool Calling & ReAct Loops

Function calling, structured JSON output enforcement, memory buffers, and evaluation metrics using the RAG Triad.

Roadmap & Core Engine Track 05

Database Engineering & SQL Internals

PostgreSQL internals, indexing strategies, transaction isolation levels, query execution planning, and connection pooling.

Module 1: Storage Mechanics

MVCC & Write-Ahead Logging

Multi-Version Concurrency Control, vacuuming mechanics, transaction isolation levels (Read Committed vs Serializable), and WAL durability.

Module 2: Index Optimization

B-Trees & Execution Plans

Interpreting `EXPLAIN (ANALYZE, BUFFERS)` output, eliminating sequential scans, composite index column order, and partial indexes.

Module 3: Production Pooling

PgBouncer & ORM Tuning

Connection pool exhaustion prevention, Prisma & Drizzle query batching, and eliminating N+1 queries.
