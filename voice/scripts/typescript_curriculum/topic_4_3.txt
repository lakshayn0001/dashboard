Audio briefing for 4.3 Declaration merging and module augmentation. Core concept: Module augmentation extends interfaces from third-party libraries (such as Express.Request or NodeJS.ProcessEnv) in a strictly typed manner. Key principles: You can add fields to existing interfaces, including those from libraries. This is the supported way to type req.user in Express. Why this matters in production: Auth middleware, theme typing, plugin systems. Common pitfall to avoid: Augmenting in a file that is not included in compilation. Conflicting augmentations across packages. Practical takeaway: Module augmentation extends existing library interfaces across the compilation scope.
