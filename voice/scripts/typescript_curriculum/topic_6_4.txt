Audio briefing for 6.4 Async TypeScript on the server. Core concept: In modern strict TypeScript, catch variables are typed as 'unknown'; use instanceof narrowing to inspect runtime error instances. Key principles: Async functions always return Promise<T>. catch (err) is unknown. Why this matters in production: DB calls, HTTP client calls, background jobs. Common pitfall to avoid: Typing catch as any. Floating promises without void or await. Practical takeaway: Strict TypeScript catch clauses receive unknown, requiring instanceof or type predicates to safely read properties.
