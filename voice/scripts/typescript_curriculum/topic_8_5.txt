Audio briefing for 8.5 Dependency types and publishing. Core concept: Correct 'exports' and 'types' mapping in package.json guarantees consumers find TypeScript declaration files regardless of bundler resolution. Key principles: Libraries you publish should ship .d.ts. Apps consume types; libraries declare them. Why this matters in production: Internal UI kits, contract packages, open-source libraries. Common pitfall to avoid: Shipping types that reference another package without declaring the dependency. Practical takeaway: Placing 'types' first in conditional exports ensures all package consumers find declaration files.
