Audio briefing for 2.1 Literal types and widening. Core concept: Literal types restrict values to exact strings, numbers, or booleans; let bindings widen literals to general primitives unless preserved via as const. Key principles: let x = 'admin' becomes string; const x = 'admin' stays 'admin'. Literal unions model finite sets better than enums for most app code. Why this matters in production: Roles, HTTP methods, button variants, tab ids, workflow states. Common pitfall to avoid: Using string for a closed set of values. Forgetting widening and wondering why assignment fails. Practical takeaway: Mutable let variables widen literal values to their broader primitive types.
