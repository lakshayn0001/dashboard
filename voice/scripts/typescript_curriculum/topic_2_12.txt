Audio briefing for 2.12 DOM typing. Core concept: Always account for null when querying DOM elements; use HTMLInputElement to access .value and typed events for form handlers. Key principles: getElementById returns HTMLElement | null. Use HTMLInputElement for .value. Why this matters in production: Any browser UI not fully wrapped by React, plus understanding React's event types later. Common pitfall to avoid: Asserting HTMLElement and then reading .value. Ignoring null from DOM queries. Practical takeaway: React.FormEvent<HTMLFormElement> provides typed access to form elements without resorting to any.
