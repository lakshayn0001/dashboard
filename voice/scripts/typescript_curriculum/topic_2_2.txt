Audio briefing for 2.2 Intersection types. Core concept: Intersection (&) merges multiple object shapes into a single required contract; intersecting mutually exclusive types collapses to 'never'. Key principles: Intersection means a value must satisfy both types. Conflicting primitives collapse toward never. Why this matters in production: WithId & UserDto, React props + HTML attributes, enriched DB rows. Common pitfall to avoid: Using & when you meant |. Giant intersections instead of interfaces/extends. Practical takeaway: Intersection combines multiple object specifications into a single compound requirement.
