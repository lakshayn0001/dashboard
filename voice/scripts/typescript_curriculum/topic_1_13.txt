Audio briefing for 1.13 tsconfig.json and strict mode — beginner. Core concept: Modern Next.js & Vite web apps use moduleResolution: 'bundler' with noEmit: true ('preserve' for Next.js, 'react-jsx' for Vite); Node libraries use module/moduleResolution: 'NodeNext' with noEmit: false and declaration: true. Key principles: Apps use 'bundler' resolution because Webpack/Turbopack handle file imports. Libraries need 'NodeNext' to support Node's native ESM rules and must emit .d.ts. Why this matters in production: A wrong tsconfig silently disables half the type system. Common pitfall to avoid: Copy-pasting tsconfig without understanding module/resolution. Leaving strict false 'until later'. Practical takeaway: It tells the compiler that array lookups might access an out-of-bounds index and return undefined.
