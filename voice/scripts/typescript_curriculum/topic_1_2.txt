Audio briefing for 1.2 Tooling: install, tsc, ts-node, tsx, and editor. Core concept: Always install TypeScript as a local devDependency pinned in package.json. Use tsx for instant dev execution and tsc --noEmit for CI type-checking. Key principles: Always install TypeScript as a devDependency in the project. The editor must use the workspace compiler, not an old global one. Why this matters in production: Mismatched compiler versions cause 'works on my machine' type errors. Common pitfall to avoid: Using only a global tsc. Committing without a pinned TypeScript version. Practical takeaway: noEmit tells tsc to perform type-checking only (common in Next.js and Vite projects), while strict enables strictNullChecks, noImplicitAny, etc.
