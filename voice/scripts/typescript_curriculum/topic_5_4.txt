Audio briefing for 5.4 Generic components and lists. Core concept: Generic components infer item types directly from the passed data array, ensuring render callbacks have full access to item fields. Key principles: Generic components infer T from items and renderItem. Polymorphic components (as='a') are Advanced; do not start there. Why this matters in production: Tables, dropdowns, select components, data grids. Common pitfall to avoid: Forcing T manually everywhere because inference was set up wrong. Practical takeaway: Generic components infer T from the items prop and carry that exact type into callback signatures.
