Audio briefing for 1.10 Union types — beginner. Core concept: Only properties shared by all union constituents are accessible directly; constituent-specific fields require narrowing first. Key principles: A union is one of several types, not a mix of all fields at once. You must narrow before using constituent-specific fields. Why this matters in production: The most important modeling tool after basic objects. Server responses, UI state, role flags. Common pitfall to avoid: Accessing .length on string | number without narrowing. Using unions when an object with optional fields would be clearer — or the reverse. Practical takeaway: Array.isArray narrows a union of T | T[] to T[] in the true branch and T in the else branch.
