Audio briefing for 9.4 Contract Testing & Mock Service Worker (MSW v2) Type Safety. Core concept: Mock Service Worker v2 intercepts at the network layer while enforcing strict types on parameters, request bodies, and JSON responses. Key principles: MSW intercepts real fetch/XHR calls, meaning components use real production networking code. Explicitly passing generic parameters to http.get/http.post ensures mocks fail compilation when backend contracts change. Why this matters in production: Eliminates subtle disparities between fake unit-test mocks and real backend API payloads in integration tests. Common pitfall to avoid: Mocking global fetch directly with vi.fn() instead of using network-level interceptors. Allowing mocked response shapes to drift out of sync with backend database models. Practical takeaway: Passing the response type as the third generic parameter ensures HttpResponse.json validates the payload at compile time.
