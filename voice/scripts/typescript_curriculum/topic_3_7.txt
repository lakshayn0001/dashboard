Audio briefing for 3.7 Template literal types. Core concept: Template literal types compute string unions; combining them with 'infer' allows parsing URL route patterns and query parameters. Key principles: String types can be computed. Powerful for routes, events, CSS, i18n keys. Why this matters in production: on${Capitalize<Event>}, /users/${string}, env key prefixes. Common pitfall to avoid: Generating enormous unions that slow tsc. Using templates where a simple union was enough. Practical takeaway: Key remapping with 'as' combined with template literal intrinsics transforms property keys programmatically.
