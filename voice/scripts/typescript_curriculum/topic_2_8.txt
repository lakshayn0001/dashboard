Audio briefing for 2.8 Built-in utility types — working set. Core concept: Utility types transform existing types; use ReturnType and Awaited to infer return shapes from asynchronous service functions. Key principles: These are mapped/conditional types shipped by the compiler. Prefer them before writing custom mapped types. Why this matters in production: DTOs, React props derived from models, patch endpoints, test fixtures. Common pitfall to avoid: Omitting from a union incorrectly (may collapse discriminants). Partial of a nested object is shallow. Practical takeaway: Utility types allow extracting safe projections of domain models.
