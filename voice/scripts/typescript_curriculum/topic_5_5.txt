Audio briefing for 5.5 Next.js App Router + TypeScript. Core concept: Next.js 15 & 16 treat page 'params' and 'searchParams' as Promises; Server Components can execute typed server queries directly. Key principles: Server Components can use Node types; Client Components cannot import server modules. Params and searchParams are Promises in Next.js 15 (LTS) and Next.js 16 (current stable). Why this matters in production: All modern Next.js production applications. Common pitfall to avoid: Passing server-only modules into client components. Trusting searchParams without parsing. Practical takeaway: In Next.js 15 and 16, route params are Promises that must be resolved asynchronously.
