Audio briefing for 3.11 Variance (functions and generics). Core concept: Function return types are covariant (outputs can be narrower); function parameters are contravariant (inputs can be wider). Key principles: Returns are covariant: () => Dog is usable as () => Animal. Parameters are contravariant under strictFunctionTypes: (a: Animal) => void is usable as (d: Dog) => void. Why this matters in production: Safe event handlers, collection typings, React setState callbacks. Common pitfall to avoid: Memorizing the words without an example. Assuming generics are always invariant. Practical takeaway: Return types preserve subtyping direction: a function producing a subtype can be used where a function producing a supertype is expected.
