Audio briefing for 7.3 Type-safe PostgreSQL access. Core concept: Modern ORMs like Prisma and Drizzle infer TypeScript types directly from relational schemas, guaranteeing query results match database definitions. Key principles: pg QueryResult is generic but you still supply the row type — easy to lie. Prisma/Drizzle/Kysely generate or infer types from schema — prefer that. Why this matters in production: Type safety directly from relational database tables to service layer. Common pitfall to avoid: Casting query results as User[] without a guarantee. Confusing optional TS fields with nullable columns. Practical takeaway: Relational databases store explicit NULLs; JSON APIs often omit keys entirely. Mappers must convert between null and undefined.
