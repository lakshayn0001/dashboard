Audio briefing for 8.2 Monorepos and shared types. Core concept: Project references enable TypeScript to build multi-package monorepos incrementally, caching compiled definitions across projects. Key principles: Shared types must compile independently. Project references speed tsc in multi-package repos when set up correctly. Why this matters in production: Enterprise scale, fast CI build caching. Common pitfall to avoid: Sharing a package that re-exports Prisma models to the browser. Practical takeaway: 'composite': true enables TypeScript to build the project as part of an incremental project reference graph.
