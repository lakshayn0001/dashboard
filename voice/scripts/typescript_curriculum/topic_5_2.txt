Audio briefing for 5.2 Events, refs, and DOM in React. Core concept: useRef<HTMLInputElement>(null) models an element that is attached after mount; event handlers take generic synthetic events like ChangeEvent<HTMLInputElement>. Key principles: React events are synthetic but typed analogously to DOM events. useRef<HTMLInputElement>(null) produces a current property that is nullable. Why this matters in production: Essential for form inputs, modals, animations, and custom UI components. Common pitfall to avoid: useRef without a type param ending as never. Asserting event.target as HTMLInputElement blindly. Practical takeaway: useRef<HTMLInputElement>(null) initializes the ref with a nullable current property that is populated after mounting.
