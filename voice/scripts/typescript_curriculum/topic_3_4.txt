Audio briefing for 3.4 Mapped types. Core concept: Mapped types iterate over property keys to transform types, add/remove modifiers (+/-), and rename keys using 'as'. Key principles: Mapped types transform every property. You can add/remove ? and readonly. Why this matters in production: This is how Partial/Pick/Readonly are implemented. You need it for custom DTO transforms. Common pitfall to avoid: Mapping a union incorrectly (need distributive patterns). Forgetting modifiers copy. Practical takeaway: Mapped types iterate over each key K in keyof T and apply the readonly modifier.
