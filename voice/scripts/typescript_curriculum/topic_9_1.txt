Audio briefing for 9.1 Jest / Vitest with TypeScript. Core concept: Never use incomplete 'as User' casts in test fixtures; use strongly typed factory functions that provide complete defaults. Key principles: Vitest is the common modern choice for Vite/Next; Jest remains everywhere. Tests should import the same types as app code. Why this matters in production: Ensuring test suites catch contract breaks and regressions. Common pitfall to avoid: as User on incomplete fixtures. Duplicate interfaces in test folders. Practical takeaway: Test factories prevent incomplete mock objects from passing silently and failing unexpectedly inside tests.
