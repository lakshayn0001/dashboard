Audio briefing for 8.4 CI, emit, and source maps. Core concept: Always separate type-checking ('tsc --noEmit') from bundler transpilation in CI to ensure that broken types block deployments. Key principles: If CI does not typecheck, types are theater. Apps may compile with SWC but still must tsc --noEmit. Why this matters in production: Protecting production from type regressions and contract breaks. Common pitfall to avoid: Typechecking only locally. Shipping minified server JS without maps. Practical takeaway: tsc --noEmit validates the entire type system across all files without generating disk artifacts.
