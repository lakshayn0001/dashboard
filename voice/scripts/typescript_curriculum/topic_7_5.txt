Audio briefing for 7.5 Auth types across the stack. Core concept: Validate JWT payloads with Zod before using them as trusted session models; model client authentication as a discriminated state machine. Key principles: JWT payloads are untrusted until verified and parsed. Role as 'admin' | 'member' | 'viewer' plus type guards on the server and UI. Why this matters in production: Rock-solid security boundaries and clean permissions logic. Common pitfall to avoid: Decoding JWT without verification and calling it a User. Boolean isAdmin plus isViewer plus isMember instead of a role union. Practical takeaway: Discriminated session states eliminate ambiguous conditions like having a user object while still marked as loading.
