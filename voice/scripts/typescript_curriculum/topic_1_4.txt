Audio briefing for 1.4 Type annotations vs type inference. Core concept: Annotate public boundaries, exported function signatures, and complex state; let the compiler infer local variables and contextual callbacks. Key principles: TS infers from initialization and from context (e.g. callbacks). Annotate public function inputs and shared API boundaries. Why this matters in production: Over-annotation hides inference skill; under-annotation leaks any across files. Common pitfall to avoid: Annotating every variable. Leaving exported functions unannotated so return types drift. Practical takeaway: Contextual typing allows TypeScript to deduce the types of function parameters based on the location in which the function expression appears.
