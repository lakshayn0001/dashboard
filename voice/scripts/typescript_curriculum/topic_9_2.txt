Audio briefing for 9.2 Typing mocks and spies. Core concept: Mock clean repository interfaces rather than sprawling database clients; this keeps test types simple and decoupled from ORMs. Key principles: Untyped mocks silently accept anything. Prefer fake implementations that satisfy an interface over deep module mocks. Why this matters in production: Reliable unit tests that don't silently accept broken inputs. Common pitfall to avoid: jest.fn() returning implicit any. Mocking half of Prisma Client instead of wrapping a repo. Practical takeaway: Typing vi.fn against the interface ensures that mock arguments and resolved values match real signatures.
