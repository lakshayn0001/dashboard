Audio briefing for 3.2 typeof type operator. Core concept: In type positions, 'typeof' queries the TypeScript type of a runtime value, allowing runtime constants to act as the single source of truth. Key principles: typeof in type position queries the type of a value. This is how you derive types from runtime config and from implementation. Why this matters in production: Single source of truth: define the object once, derive the type. Common pitfall to avoid: Confusing JavaScript typeof with the type operator. Practical takeaway: typeof extracts the type signature of the function, which ReturnType unwraps to retrieve its output shape.
