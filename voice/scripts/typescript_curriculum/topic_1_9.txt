Audio briefing for 1.9 Interfaces — beginner. Core concept: Interfaces are open for extension and declaration merging; type aliases cannot be merged and can model unions and primitives. Key principles: Interfaces are extendable and merge across declarations. Types are better for unions, tuples, mapped types. Why this matters in production: Public object contracts, library typings, React props in many codebases. Common pitfall to avoid: Merging by accident when files repeat the same interface name. Using interface for a union. Practical takeaway: Interfaces with the same name in the same scope merge automatically, enabling library augmentation.
