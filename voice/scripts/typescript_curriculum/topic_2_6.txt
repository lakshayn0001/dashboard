Audio briefing for 2.6 Classes and OOP in TypeScript. Core concept: TS 'private' is only checked at compile time and can be bypassed; JS '#field' provides true runtime encapsulation; credentials injected via config. Key principles: TS private is compile-time only; #field is runtime private. implements checks the instance side, not static side fully. Why this matters in production: NestJS, ORMs, React class components (rare), domain services. Common pitfall to avoid: Using classes for bags of functions with no identity. Forgetting that implements does not copy methods. Practical takeaway: Prefixing constructor parameters with accessibility modifiers automatically generates and initializes class member fields.
