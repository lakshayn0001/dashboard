Audio briefing for 3.5 Conditional types. Core concept: Conditional types provide if-else logic at the type level. Unwrapped type parameters distribute across unions automatically. Key principles: Conditionals are type-level if/else. Naked type params distribute over unions. Why this matters in production: Utility types, library APIs, 'if the arg is X, return Y' functions. Common pitfall to avoid: Unexpected distribution producing unions you did not want. Deep nested conditionals nobody can read. Practical takeaway: Naked type parameters distribute across unions; matching members evaluate to never, which is filtered out of the union.
