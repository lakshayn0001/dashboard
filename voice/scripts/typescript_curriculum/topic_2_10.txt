Audio briefing for 2.10 Enums — use sparingly. Core concept: Numeric enums generate surprising runtime code and have unsound number assignability; const objects + union types tree-shake cleanly. Key principles: Enums are a real runtime object (except const enums). Numeric enums are especially surprising. Why this matters in production: Interviews and legacy Nest/Java-style codebases. Common pitfall to avoid: Numeric enums for states. const enums + Babel without proper config. Practical takeaway: as const objects paired with derived unions provide zero-runtime-cost enum alternatives that tree-shake cleanly.
