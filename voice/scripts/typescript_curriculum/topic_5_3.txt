Audio briefing for 5.3 Hooks typing. Core concept: Pair useReducer with discriminated action unions; wrap createContext in a custom hook that throws if accessed outside its provider to eliminate null checks. Key principles: useState<User | null>(null) is a classic required annotation. Reducers pair perfectly with discriminated unions. Why this matters in production: Application state management, global context, and custom reusable logic. Common pitfall to avoid: State typed as any. Context default null without a guard hook. Practical takeaway: An explicit tuple return type [boolean, (next?: boolean) => void] prevents TypeScript from widening the return array to (boolean | ((next?: boolean) => void))[] and allows caller-driven toggling or direct setting.
