Audio briefing for 3.10 Type compatibility and structural typing. Core concept: TypeScript uses structural subtyping ('duck typing'). Fresh object literals undergo excess property checks, but assigned variables follow pure structural shape rules. Key principles: TS compares shapes, not names. Two different interface User and interface Person with the same fields are compatible. Why this matters in production: Explains 'why does this assignment work?' — a constant interview theme. Common pitfall to avoid: Expecting nominal safety from type UserId = string. Confusing excess property checks with general assignability. Practical takeaway: TypeScript uses structural subtyping: two types are assignable if their required properties match.
