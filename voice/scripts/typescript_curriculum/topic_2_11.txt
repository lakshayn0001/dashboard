Audio briefing for 2.11 Modules: ESM, import type, and file structure. Core concept: import type guarantees that the import will be completely elided from the JavaScript output, preventing circular dependencies and bundler bloat. Key principles: import type makes it clear the import is erased. Barrel files (index.ts) can cause cycles; use carefully. Why this matters in production: Every app. Wrong imports cause runtime undefined and circular deps. Common pitfall to avoid: Importing types as values accidentally under isolatedModules. Giant barrels that pull the whole app. Practical takeaway: 'import type' guarantees that the imported symbol is completely elided from the compiled JavaScript bundle.
