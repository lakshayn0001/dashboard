Audio briefing for 1.6 Functions — beginner. Core concept: A function signature returning 'void' allows callers to ignore the return value, which is why Array.prototype.forEach allows return statements. Key principles: Optional ? is different from | undefined in call sites (caller can omit ?). A function that returns a value can still be assigned to () => void (return value ignored). Why this matters in production: Every handler, mapper, predicate, and service method is a function type. Common pitfall to avoid: Typing callbacks as Function (loosens all checking). Forgetting return type on recursive functions. Practical takeaway: Function type expressions define the parameter types and return type signature cleanly for reuse across algorithms.
