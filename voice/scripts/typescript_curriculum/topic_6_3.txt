Audio briefing for 6.3 Express typing. Core concept: Express request generic signature is Request<Params, ResBody, ReqBody, ReqQuery>; error middleware must have exact 4-parameter arity. Key principles: Express types are loose on req.params / query (strings). You still parse with Zod. Why this matters in production: Standard REST APIs built on Node.js. Common pitfall to avoid: Typing req.body as a domain object without parsing. Wrong error middleware arity. Practical takeaway: Express Request accepts generic parameters: Request<Params, ResBody, ReqBody, ReqQuery>.
