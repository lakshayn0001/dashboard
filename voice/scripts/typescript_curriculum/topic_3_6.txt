Audio briefing for 3.6 infer keyword. Core concept: The 'infer' keyword introduces a type variable within the conditional 'extends' clause to extract internal types like return values and promises. Key principles: infer X introduces a type variable from a matching pattern. This is how ReturnType and Awaited work. Why this matters in production: Deriving element types, payload types, middleware signatures. Common pitfall to avoid: Using infer outside conditional types. Overly clever infer chains. Practical takeaway: The infer keyword introduces a pattern-matched type variable inside the extends clause of a conditional type.
