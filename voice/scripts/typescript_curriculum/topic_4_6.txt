Audio briefing for 4.6 TypeScript compiler API and transformers. Core concept: The TypeScript Compiler API enables custom AST transformers, codegen tools, and custom typed lint rules. Key principles: Rare in product work; used in codegen, ESLint rules, and documentation tools. Not required for everyday full-stack proficiency. Why this matters in production: Tooling authors, custom linter development. Common pitfall to avoid: Building a transformer when a simpler codegen script would do.
