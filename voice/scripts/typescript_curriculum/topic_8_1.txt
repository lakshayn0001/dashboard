Audio briefing for 8.1 Project architecture for TS full-stack. Core concept: Isolate shared contracts from implementation code; use 'server-only' package in Next.js to prevent backend credentials from leaking into bundles. Key principles: Colocate feature types unless they are true shared contracts. A types.ts dump of everything becomes unmaintainable. Why this matters in production: Maintainability across growing teams and multiple applications. Common pitfall to avoid: One giant global.d.ts for app models. Circular barrels. Practical takeaway: The 'server-only' package throws a build-time error if server modules are bundled into client code.
