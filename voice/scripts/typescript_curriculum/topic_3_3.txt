Audio briefing for 3.3 Indexed access types. Core concept: T[K] extracts property types; T[number] extracts the element type of arrays or tuples without manual duplication. Key principles: T[K] is the type of property K. If K is a union of keys, result is a union of those property types. Why this matters in production: Extracting DTO field types, element types of const arrays, API envelope .data types. Common pitfall to avoid: Using string where K must be keyof T. Forgetting optional properties add | undefined. Practical takeaway: Indexing a tuple or array with [number] retrieves the union of all element types in the collection.
